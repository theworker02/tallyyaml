# tallyyaml

Tally URLs and yaml query parts with stable normalization.

**Site:** https://theworker02.github.io/tallyyaml/

## Install / run

```bash
git clone https://github.com/theworker02/tallyyaml.git
cd tallyyaml
node src/cli.js
node --test
```
